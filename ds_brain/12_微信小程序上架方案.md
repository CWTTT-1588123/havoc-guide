# 微信小程序上架方案（ds_brain 12）

> 目的：把「海克斯大乱斗攻略站」上架为**微信小程序**。
> 已确认决策（2026-09，用户拍板）：
> - **主体 = 个人身份证**（非企业/个体户）
> - **第一版不含 AI 聊天**（SSE 不支持 + 深度合成类目风险；聊天留网页版，后续用 WebSocket 补）
> - 技术路线 = **uni-app（Vue 3 + Vite）**，复用现有 `havoc_guide/web/` 代码，后端 FastAPI 基本不动

---

## 一、为什么这样定

| 候选路线 | 结论 | 原因 |
|---|---|---|
| web-view 套壳 | ❌ | 个人主体小程序**不支持 web-view 组件**；纯网页套壳审核大概率被拒 |
| 原生小程序（WXML/WXSS） | ❌ | 现有 Vue 3 组件全作废，重写量大 |
| **uni-app（Vue 3）** | ✅ | 与现有代码语法几乎一致：`div→view`、`fetch→uni.request`、`localStorage→uni.setStorageSync`；v1.3 移动端 CSS 可直接换算 rpx |

**已有资产（都能用）**：
- 后端 36 个接口全部可复用；鉴权 = `Authorization: Bearer <token>`（非 Cookie）→ 小程序直连无障碍。
- `haikelol.com` 已 HTTPS + ICP 备案（蜀ICP备2026051382号-1）+ 公安备案 → 满足小程序 request 合法域名硬性要求。
- v1.3 手机端样式（`11_移动端兼容需求.md`）→ 小程序版式的现成蓝本。

## 三、第一版功能范围（v1）

**TabBar 三页**：
1. **首页**：英雄胜率排行榜（综合/纯/场次排序、升/降序、搜索、分页、前三符文）——对应 `HomeView.vue`
2. **符文**：全部符文页 + 6 大分类页——对应 `AllAugmentsView.vue` / `CategoryView.vue`
3. **我的**：登录/注册（邮箱+验证码+忘记密码+绑定手机）+ 个人中心（资料/主题/桌宠/背景）——对应 `LoginModal.vue` / `ProfileView.vue`

**页面路由**（非 TabBar）：
- `pages/champ/champ?id=804`：英雄详情（胜率/最优单符文/组合/出装/克制/评论区）
- `pages/category/category?cat=刺客`：分类页（也可并入 tab 2）
- `pages/section/section`：详情"更多"板块（`SectionView.vue`，有则迁，无则并入详情页）

**不上**：AI 聊天、管理后台、深色主题的电脑端悬浮提示逻辑（小程序全部触屏，走 v1.3 手机交互）。

## 四、工程与技术要点

- **新目录**：`E:\Deepseek Harness\havoc-mp\`（uni-app Vue3 Vite 工程，独立于 `havoc_guide/web`）。
- **API 封装** `src/api.js`：`uni.request` 封装 `request()/getJSON()/apiAuth()`，baseURL `https://haikelol.com`，token 存 `uni.setStorageSync('dsh_auth')`；对应改造 `store.js`（去 `document/localStorage/window` 依赖）。
- **样式**：新建 `src/styles/app.scss`（uni-app 用 rpx）：把 v1.3 ≤768px 媒体查询里的手机样式**提为主线样式**，色板/深色模式用 CSS 变量保留（小程序只发 v1 浅色，深色可后补）。
- **图标**：英雄/符文头像现在走 ddragon/communitydragon CDN——小程序 `<image>` 外链不需要域名白名单，但国内访问慢/不稳 → **镜像到自己 ECS**（如 `https://haikelol.com/icons/champ/<id>.png`），本地从 ddragon 拉齐后 scp 上服务器（172 英雄 + 208 符文）。头像 onerror 兜底：`avFallback` 的 SVG data-uri 在小程序里不可用 → 改成本地占位图。
- **分享**：详情页 `onShareAppMessage`（分享英雄战绩卡）+ 首页分享。
- **登录**：沿用 `/api/auth/*` 邮箱体系；微信一键登录（`code2session`）列为 v2 可选项。
- **后端改动清单**（`havoc_guide/webapp.py`）：
  1. 评论接口（`/api/champion/{cid}/comments` POST）加**敏感词过滤**（命中即拒，返回明确提示）；
  2. （可选）`/api/version` 无需改；确认 `/api/site` 已含 icp/police 字段 ✅；
  3. 无 CORS 改动（小程序无浏览器同源限制）；
  4. 单进程 `--workers 1` 够用，上线后看 QPS 再决定。

## 六、风险与规避

| 风险 | 概率 | 规避 |
|---|---|---|
| 个人主体类目不含游戏资讯 → 审核驳回"类目不符" | 中 | 以「工具-信息查询」定位；名称/文案强调"数据查询工具"；被驳回按审核意见改，或注册个体户主体（一年一验） |
| 备案前置审批（出版/游戏灰区） | 低 | 攻略站属资讯非游戏本体，通常不触发；备案若被卡，在备案材料里如实申报"资讯查询工具" |
| ddragon CDN 国内慢 | 高 | 图标镜像到自己 ECS（阶段 4 必做） |
| uni-app 与微信基础库兼容 | 低 | 用 uni-app 最新正式版 + Vue3 Vite 模板，构建目标 `mp-weixin` |
| 评论区 UGC 违规被连带处罚 | 中 | 敏感词过滤 + 保留管理员删评 + 用户协议 |
| 商标（LoL/Riot） | 低 | 保留免责声明；不用 Riot 商标做 logo/名称；logo 用自绘「海克斯」图标 |
