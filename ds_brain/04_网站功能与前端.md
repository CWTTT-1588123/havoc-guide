# 网站功能与前端（当前）

> 目标：**最快最直接**给玩家"这英雄该带什么符文/怎么打"。单页 SPA，全在 `havoc_guide\static\index.html`（每次实时读取，改前端**无需重启后端**）。

---

## 一、后端 `webapp.py`（FastAPI）

### 关键常量
- `PATCH_VERSION`（默认 `16.16`）：数据口径 + 网站"版本"徽标。
- `DRAGON_VER`：DDragon 版本，**自动取最新，兜底 `16.17.1`**。头像/出装图标用它拼 URL。
- 启动读：`stats.json` + `champion_names.json` + `item_names.json` + `augment_names.json` + `augment_icons.json`。

### 接口
| 路由 | 说明 |
|---|---|
| `/` | 返回 `static/index.html`（每次实时读文件） |
| `/api/champions` | 排行榜：每英雄 `id,name,image,wr,games,wilson,best3[{name,quality,icon}]` |
| `/api/champion/{cid}` | 英雄详情（见下） |
| `/api/augments_global` | 全局符文 |
| `/api/augments_all` | 所有符文，按品质分组 `[{quality,items[{id,name,en,desc,icon,quality}]}]` |
| `/api/version` | 返回 `{game_version}` |

### `/api/champion/{cid}` 关键加工
- `augments_by_quality`：单符文按 白银/黄金/棱彩 分组，每档≤15。
- `combos`：过滤 `<2` 个聚合，补 `augment_meta[{id,name,quality,icon}]`，≤20。
- `synergy`：补 `aname/aquality/bname/bquality/aicon/bicon`，≤15。
- `builds`：**补 `item_icons`**（按物品 `items[]` 的 id 拼 `https://ddragon.leagueoflegends.com/cdn/{DRAGON_VER}/img/item/{id}.png`），≤15。
- `counters`：**过滤"质变/潘朵拉"（A类随机）**，补 `augment_quality`，≤15。

## 二、前端 `static/index.html`（单页 SPA）

### 页面 1：首页（排行榜）`renderHome` / `renderChampsList`
- **搜索框独立一行、拉长**：`placeholder="搜索英雄"`；支持**外号/简称搜索**（内置 583 条"昵称→官方名"映射，大小写无关；搜索/排序时自动回第 1 页）。
- **排序**：综合胜率(Wilson) / 纯胜率 / 场次 + 正倒序切换。
- **分页**：默认**每页 20**，可选 **20/50**；左右箭头 ‹ ›；`第 X / Y 页 · 共 N 个英雄`；箭头到边界禁用；切换每页数量回到第 1 页。
- **表头吸顶**：`<thead>` `position:sticky`，`top:var(--headerh)`（动态测品牌栏高度）；**与"海克斯大乱斗 攻略站"品牌栏同底色融合**（`--bar`），无缝。
- **字段**：头像 | 英雄 | 胜率(低变红) | 场次 | 前3符文(`augChip` 深色带图标)。
- 点行 → `openChamp(id)`。

### 页面 2：英雄详情 `openChamp(id)`
- 顶部：头像、名字、**整体胜率+场次**。
- **板块导航**（整体胜率下方，横向按钮，`jumpTo` 平滑滚动+避开品牌栏）：最优单个符文 / 最优符文套路 / 搭配增益 / 核心出装 / 克制推荐（仅显示有数据者）。
- **板块**（每个：标题 + 小字说明 + 内容 + 右下角"`更多 ›`" + 结尾 1px 发丝线 `.secend`，最后一块隐藏线）：
  - `最优单个符文`：**三品质并排**（白银/黄金/棱彩），单符文卡（大图标、等高、深色渐变），`更多 ›`→详见页。
  - `最优符文套路`（默认6）：**3 符文** chips + 场次 + **收缩点估计胜率 est + ▲/▼ 与英雄平均差值**（说明"这三个符文一起带的胜率，比该英雄平均▲高/▼低"；2026-09-09 晚起）。
  - `搭配增益`（默认6）：`A+B`、一起胜率(绿)、`▲/▼增益%`；说明"这两个符文一起带，胜率比该英雄平均▲高/▼低"。
  - `核心出装`（默认6）：**深色带装备图标**的 chips。
  - `克制推荐`（默认6）：`[敌方类型] → 符文(品质) ▲X%`；说明含"**▲ 克制加成 / ▼ 反被压制**"。

### 页面 3：分类排名页 `openCategory(cat)`
- 「英雄」表头旁 **▲▼ 按钮式触发器**，悬停弹出**五行分类列表**（刺客/战士/法师/射手/辅助，各带主题色圆点+数量）；点击卡片进入。
- 分类页：**彩色横幅**（主题色渐变，与主页表格区分）+ **英雄卡片网格**（奖牌名次/头像/胜率主题色/场次/最优符文），卡片点击进英雄详情。
- 分类归属：**Riot Data Dragon 官方职业 tags**（主职业定，坦克按副职业归入 战士/辅助/法师）；本站 172 英雄覆盖。

### 页面 4：所有符文 `openAllAugments`
- **三品质标题条吸顶、依次跟随堆叠**（装入同一 `.qlist` 长容器作包含块；`position:sticky` + 递增 `top`；`--i` 0/1/2；完全贴死、无圆角）。
- 点标题条展开该品质的深色渐变卡（`augCard`）。**卡片等宽等高（2026-09-13 定稿）**：
  - **等宽**：`.auggrid { grid-template-columns:repeat(N,minmax(0,1fr)) }`——必须用 `minmax(0,1fr)` 而非 `1fr`（`1fr`=`minmax(auto,1fr)`，描述里的长不可断行串会把该列撑宽，例如「缩小引擎」有 60 个连字符 ≈660px）；配合 `.augcard-wrap{min-width:0}`、`.augcard{overflow:hidden}`、`.sname/.sdesc{overflow-wrap:anywhere}`。
  - **等高（403px）**：三段固定高度——图标 104px + 名称区 `height:2.6em`(2 行) + 描述区 `height:8.7em`(6 行)，均超出即省略号；改高矮只改这两个数字。
  - **点击卡片（电脑端+手机端）→ 居中弹窗**显示完整卡片（图标+名称+品质+完整描述）；弹窗开着时抑制悬浮提示。
- 无图标符文用占位框；悬停符文卡 → 效果提示。
- 页面副标题提示"点击任意符文卡片查看完整效果说明"。

### 全局组件
- **悬停符文效果提示** `.tt`：`mouseover/mousemove/mouseout` 委托，按 `data-name` 从 `/api/augments_all` 的 `desc` 取效果，深色浮框，光标旁弹出，靠边翻转，移开 120ms 隐藏。
- **回到顶部**：已删除（用户要求）；右下角为**版本号** `.verlabel`（黑字，Q 版角色下方）。
- 头像兜底 `avimg()`：图片 404 时换"英雄名字首字"占位（新英雄 16.17 后才有图）。

## 四、关键决策（为什么）
- **Wilson 下界排序**（z=1.96）：胜率+样本量加权，压掉"小样本 100%"虚高。
- **分类用 Riot 官方 tags** 而非自定：权威；坦克按副职业归入 战士/辅助/法师，保证五类全覆盖。
- **出装图标用 DDragon 标准物品图标**：见 03「数据决策」。
- **符文效果悬停取自 Kiwi 符文编号表**（`desc`），不是图里抠的。
- **每页 20/50 可选**：默认 20，兼顾信息密度与可读。
- **网页头像/出装图标统一 `DRAGON_VER`**：与头像同版本，避免新旧图并存。

## 五、登录 / 个人中心（当前）

### 后端 `webapp.py`（本地演示登录）
- 本地用户表 `processed/users.json`（`id,name,contact,salt,phash(sha256+盐),avatar,tokens[],is_admin,created`）；**首个注册用户 = 管理员**。
- **多 token**：每个用户存 `tokens` 列表（登录不再覆盖旧会话，多端互不顶掉）；`_auth_user` 校验 Bearer token。
- 接口：`/api/auth/send_code`（**演示：直接把验证码返回给前端显示**，`CODES[contact]` 存 6 位码+10min 过期）、`register`、`login`（验证码 或 密码）、`me`、`avatar`（base64 存 `static/avatars/`）、`password`、`name`、`logout`。
- `/static` 挂载（`StaticFiles`），头像/预设头像经此访问。

### 前端
- **标题栏「登录/注册」**：点击弹居中登录窗（**短信/验证码登录** + **密码登录** 两个 tab；手机号/邮箱切换 + 获取验证码(显示验证码) + 验证码 + 设置密码；密码登录：账号+密码+忘记密码+注册）。
- **登录后**：按钮变**圆形头像**（深色圆环、无方框），悬停弹**B 站风格菜单**（头像/昵称/管理员徽章/关注·粉丝·动态/个人中心/主题：浅色·深色/退出登录）；菜单**淡入淡出 + 260ms 延迟隐藏**（不闪断）。
- **个人中心页**（点头像/菜单"个人中心"进入，页面框架内）：
  - **我的账号**：圆形头像(点击更换/预览上传)、昵称、账号、**更换头像 / 更改密码 / 更改用户名**（内嵌表单，成功绿色 toast + 自动收起）、退出登录。
  - **自定义网页背景**：预设**浅色色票** + **上传图片背景** + 恢复默认（用户偏好存 localStorage `dsh_prefs_<uid>`）。
  - **锁定 Q 版人物形象**：点击**多选/取消** + **确定**按钮，锁定单/多个（桌宠在锁定集合内随机）。
  - **改变网站风格**：浅色/深色（选中→**确定**）。
- **未设头像**显示**预设头像** `preset_avatar.png`（金色 LOL "L"）。
- **偏好持久化**：`localStorage 'dsh_prefs_<uid>'`（bg/bgImg/pets/theme）——登录用户各自独立、可更换浏览器保留。

## 八、登录/认证系统（已上线）
> 详细见 `05`/`00` 与 `ds_done` 日志。这部分在**生产环境**验证通过。

### 后端（`webapp.py`，用户表 `processed/users.json`）
- **注册**：仅**邮箱**（`register`/`register_pub`，校验邮箱格式，邮箱唯一）。
- **登录**：密码登录（`/api/auth/login`，账号=邮箱**或绑定手机号**，`_find_account` 自动识别）、邮箱验证码登录（`register`→`login` 回退）。
- **验证码真发**：`/api/auth/send_code` 通过 **163 SMTP** 真发（配置在 `/root/.env`；返回 `sent:true`，前端不再显示码）；邮箱格式错→「邮箱输入错误」。
- **忘记密码**：`/api/auth/forgot`（发重置码）+ `/api/auth/reset`（验证码+设新密码）。
- **绑定手机号**：`/api/auth/phone`（需登录；手机号唯一：一机一号）。
- **密码**：sha256+盐哈希；**多 token 会话**（登录追加 token，不互相顶掉）。
- **角色体系**：最早创建的管理员 = **主管理员**(`_is_owner`，列表置顶/权限最大)；普通管理员只能管普通用户；保护：不能降自己/不能降最后管理员/不能删主管理员。
- **管理后台**：`/api/admin/users|user/{id}|delete/{id}`（需管理员权限）。

### 前端（`static/index.html`）
- **登录弹窗**：白底(560px)、顶部标签一行；**验证码注册**（邮箱+验证码+设置密码+确认密码，密码占位「请至少输入六位数」）+ **密码登录**。
- **密码框小眼睛**：睁眼/闭眼 **SVG**（默认闭眼，关闭弹窗后重置；点击切换显示/隐藏）。
- **头像悬浮菜单**：**不透明**（浅色白底/深色深灰），含"个人中心/管理后台(管理员才见)/主题/退出"。
- **个人中心**：我的账号(更换头像/改密码/改用户名/**绑定手机号**/退出)、自定义背景、锁定Q版、主题。
- 管理员入口：头像菜单 → **管理后台**（用户列表/设为/降为/重置密码/删除）。
