# 移动端兼容需求（ds_brain 11）

> 状态：**✅ 已实施并部署上线（v1.3）**。前端为 Vue（`havoc_guide/web`），样式在 `web/src/style.css`（原版 CSS 逐字段 + Vue 补充段）与 4 个组件的 `<style scoped>`（Pet/ChatBot/LoginModal/AvatarMenu）。
>
> ⚠️ **双端差异化**（用户要求）：桌面端保持 v1.2 原样（胜率/场次两列、175px 卡片三品质并排、悬浮提示、克制一行、个人中心横排）；手机端为新样式（排名徽章、三排符文、两列卡+金/银/铜序号、品质小字、居中弹窗、克制两行、个人中心三行竖排）。实现方式：HomeView 双渲染列（c-wr/c-games 桌面 / c-rank 手机）、comboRow 场次双渲染（num-desk/num-mob）、App.vue 按 `matchMedia('(hover:hover)')` 分流（电脑悬浮提示 / 手机点击弹窗）、其余规则拆入 ≤768 媒体查询。

---

## 一、现状（桌面优先，手机不友好）
- 基础字号 **26px**、输入框 `min-width:320px`、搜索框 `width:540px`。
- 顶栏 = 品牌 + 搜索 + 登录 **一行横排**，窄屏会溢出。
- 首页排行榜表格 **5 列**（头像/英雄/胜率/场次/最优符文），手机上会横向溢出。
- 工具栏按钮大而多（综合/纯/场次/升降/英雄分类/查看所有符文）。
- 已有响应式：仅 `.aqgrid`（≤1000px 单列）、`.auggrid`（6/4/3/2/1 列）——覆盖不全。
- 桌面优先 => 手机上：顶栏挤爆、表格出屏、字太大、按钮太大。

## 二、目标
手机（360/375/390/414px 宽主流机型）上**排版正常、不横向溢出、可正常点按**；深浅模式都适配；**不动现有功能逻辑，只做 CSS 适配 + 极少量模板微调**。

## 三、需求清单
| # | 区域 | 要求 |
|---|---|---|
| 1 | **顶栏** | 品牌缩小；搜索框**换行独占一行全宽**；登录按钮紧凑；整体不溢出 |
| 2 | **首页表格** | 手机上**只纵向滚动、不横向滚动**：表格改为**竖排卡片列表**（隐藏表头，每行一张卡：英雄名 + 胜率/场次右侧 + 最优符文整行）；行高/字号缩小 |
| 3 | **全局字号** | ≤768px 时整体缩小（body/按钮/表格/输入框同步），点按目标尽量 ≥44px |
| 4 | **输入框/搜索** | 去掉 `min-width:320px`，手机上全宽自适应 |
| 5 | **工具栏按钮** | 缩小、自动换行（已 flex-wrap），选中态/图标正常 |
| 6 | **英雄详情** | `.dhead` 头像+信息可换行；板块导航按钮换行；单个符文卡（`.singlecard`）手机上自适应宽度；更多页/评论区正常 |

## 四、怎么做（已完成）
1. **CSS 优先，不改逻辑**：在 `style.css` 的 **Vue 补充区末尾**追加两档媒体查询覆盖层：
   - `@media (max-width:768px)`：全局字号、顶栏换行、搜索全宽、输入框去 min-width、`html,body{overflow-x:hidden}`、`.dhead/.pc-*` 换行、聊天窗/桌宠尺寸。
   - `@media (max-width:480px)`：字号再缩、按钮 padding 缩小、卡片网格、分页按钮缩小。
2. **表格（用户要求改为纵向）**：`#tbl` 手机端 `display:block` 隐藏 `thead`，`tr.row` 变 flex 卡片（背景 `--panel`、圆角、阴影），`td:nth-child(1)` 占满剩余、`td:nth-child(2/3)` 右对齐、`td:nth-child(4)` 整行显示符文。**不做横向滚动**。
3. **⚠️ 组件 scoped 样式覆盖问题**：Pet/ChatBot/LoginModal/AvatarMenu 的 `<style scoped>` 选择器带 `[data-v]`，特异性高于全局媒体查询 → 全局覆盖无效（桌宠一直 180px 就是此原因）。解法：媒体查询**同时写进各组件 scoped 样式内**（已做：Pet 64/56px、ChatBot 窗 94vw、LoginModal/AvatarMenu 字号与宽度）。
4. **修正死选择器**：`.brand` → 实际类名 `.titlebtn`（顶栏品牌 h1）；`.verlabel` 移到左下角避免与桌宠重叠。
5. **逐页验收**：浏览器 F12 移动模拟（iPhone SE/12/14、安卓 360/412）逐页看 → 再用**真机**微信/浏览器开 haikelol.com 验证。
6. **构建 + 部署**：`npm run build` → scp `web/dist` → 强刷验证（同 v1.2 流程）。
7. **回归**：桌面端不能变差（媒体查询只作用于小屏）。

## 五、验收标准
- 360px 宽手机：任意页面**无横向滚动条**（除表格内刻意滚动）、文字可读、按钮可点。
- 桌面端（≥769px）观感与现状**一致**。
- 深浅两种模式都通过。
- 聊天流式、桌宠气泡、登录等交互正常。
