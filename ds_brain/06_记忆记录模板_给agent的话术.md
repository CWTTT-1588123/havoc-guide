# 记忆记录模板（给 agent 的话术）

> **用途**：下次想"记录记忆/状态"时，**直接把下面对应的话术复制给 agent**（或只报模板编号，如"按模板①全面记录"），即可触发记录，**不用重新打字**。
> **通用**：把 `【占位】` 替换成实际内容即可，任何项目都适用。
> **token**：这些记录只写磁盘（`ds_brain`），**本身不占 token**；不触发就不记录。想启用哪条就发哪条。

---

## 0 怎么用（给用户的说明）
- 下面每题是"一键话术 + agent 要做的事"。
- 想要哪种记录，就复制对应话术给 agent（或只报编号）。
- 记录要 **准确、基于当前真实状态**，agent 需先读项目文件核实，再写。

---

## ① 全面记录（建档 / 整体快照）——最常用
【话术】
```
把【项目名】这个项目工作的全过程，整理好文字，直接收录最正确最直接的那条路线，
方便你（agent）查看以便了解项目、工作衔接更流畅，也方便我学习。
整理好全过程路线以及当前进度，放进一个新的文件夹 ds_brain 里面。
一定要全面详细，不要遗漏每一步。
```
【agent 要做】
1. 读项目关键文件（代码/数据/配置）；
2. 核实**当前真实状态**（对局数/后台任务/数据规模/最近改动/运行中的服务）；
3. 在 `ds_brain` 里写成多份文档：**总览**（架构/进度/快速上手/文件清单）、**全过程路线**、以及按需的**数据获取/管线统计/网站/运行手册+当前进度**；
4. 确保**准确、无遗漏**，并把"当前进度"写清。

---

## ② 更新当前进度（快照刷新）
【话术】
```
把【项目名】当前进度更新一下：对局数、后台任务、数据规模、最近改动。
放进 ds_brain 的"总览/当前进度"里。
```
【agent 要做】
1. 扫描工作区（数据文件数、后台任务状态、`stats.json` 元信息、最近改动文件）；
2. 更新 `ds_brain` 里的"当前进度"表，保持与硬盘一致。

---

## ③ 补充"为什么 / 路线"决策
【话术】
```
把【这次的决定/为什么这么做】整理进 ds_brain 对应的文档（如"全过程路线/统计口径"），说明原因和取舍。
```
【agent 要做】
- 把这次的关键决策、理由、权衡写入 `ds_brain` 相应文档，保持与现状一致，避免与旧内容矛盾。

---

## ④ 记录"做了什么"（ds_done）
【话术】
```
在 ds_done 里记一条：做了【具体做了什么 / 改了哪些文件 / 结果数字 / 遇到的异常】。
```
【agent 要做】
- 追加到 `ds_brain\ds_done\run_log.jsonl`，**单行 JSON**：`{time, action, target, result, note}`（只追加，不改旧记录）。

---

> 模板本身可扩展（新增一类记录就加一条）。改模板时尽量保持"一句话 + agent 要做的事"的结构。
