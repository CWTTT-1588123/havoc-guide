# 数据管线与统计口径（详细）

> 把抓到的原始对局数据，变成有意义的"胜率 + 推荐"。

---

## 一、管线总览
```
data\detail_*.json  (原始, ~9971个)
        │ extract.py
        ▼
processed\records.jsonl  (每行=一场对局里的一个玩家, 结构化)
        │  metadata.py (DDragon 英雄/装备中文名) + augment_names.json(Kiwi符文名)
        ▼
processed\stats.json  (统计结果, 供网站)
        │  webapp.py (FastAPI)
        ▼
前端 static/index.html
```

---

## 二、`extract.py` —— 原始JSON → 结构化
- 遍历 `data\detail_*.json`，只处理 `game_mode=="KIWI"`，按 `game_id` 去重。
- **胜负判定**：读取 `battle_detail.team_details[]` 的 `{teamId, win}`，玩家 `teamId` 对应即可得 `win`（true/false）。
- **符文**：`playerAugment1~6` 取非空的组成列表 `augments`（整数ID）。
- **装备**：`item0~6` 取非空的组成 `items`。
- **阵容**：按 `teamId` 分组，得到 `ally_champs`（同队其它英雄）和 `enemy_champs`（敌对英雄）——**克制推荐依赖 enemy_champs 的标签**。
- 还存：`version`(补丁)、`start_time`、`duration`、`kills/assists/deaths`、`gold`、`score`、`damage`、`level`、`player_name`。
- 输出 `records.jsonl`（每行一条，含 `game_id`+10个玩家）。

**为什么这样设计**：一张表 = 一场对局 × 一个玩家，方便按英雄/符文/阵容维度聚合统计。

## 三、`metadata.py` —— ID→名字/头像
- **英雄**：DDragon `champion.json`，`key`(数字id) → `{name(中文), id(英文key), title}` → `champion_names.json`。
- **装备**：DDragon `item.json`，`id` → `中文名` → `item_names.json`。
- **符文**：`augment_names.json` 来自 **Kiwi 表**（见下），`id → {name(中文), quality(白银/黄金/棱彩), desc, en}`。

### 符文名来源：Kiwi 表（关键）
- 文件：`E:\英雄联盟符文id\kiwi\augments.json`（222个：`id / name / cn / en / desc / rarity / ver`）。
- **校验**：我们数据里 210 个增援ID **全部命中 Kiwi 表（缺=0）** → 同一套编号，可直接引用。
- 用 `rarity` 映射品质：`kSilver→白银`、`kGold→黄金`、`kPrismatic→棱彩`（`kEpic→史诗`）。

### 版本 / 图标来源决策（重要）
- **头像版本**：`DRAGON_VER` 自动取最新、兜底 `16.17.1`。曾用 `15.14.1` 时新英雄（灰烬驱魔人 Locke / 不落魔锋 Zaahen 等）**无头像图（403）**；改到 **16.17.1** 后全站 172 英雄头像齐全。
- **出装图标**：站点构建数据用**标准 LoL 物品 id**（狂战士胫甲=3006、破败王者之刃=3153、无尽之刃=3031 等），**0 件是 ARAM 专属的 771xxx**。故出装图标用 **DDragon 标准物品图标** `…/cdn/{DRAGON_VER}/img/item/{id}.png`；`E:\英雄联盟符文id\海克斯大乱斗装备图文对照表.md` 里的 771xxx **本地图标未使用**（与站点物品号不匹配）。若确要乱斗专属图标，需另做"标准号→乱斗号"映射并托管本地图片。
- **英雄分类**：Riot Data Dragon 官方职业 tags（主职业定类）；坦克按副职业归入 战士/辅助/法师，保证五类全覆盖。

## 四、`stats.py` —— 统计引擎

### 4.1 置信度 / 样本量（防止小样本误导）
```python
def wilson_lower(k, n):  # Wilson 下界，z=1.96
    p = k/n; denom = 1 + z*z/n
    center = p + z*z/(2*n)
    margin = z * ((p*(1-p)/n + z*z/(4*n*n))**0.5)
    return (center - margin)/denom
```
- 排序用 `wilson`（胜率+样本量综合），避免"3场100%冲顶"。
- 各板块设**最小样本**：单个符文 `MIN_GAME`(默认10)、组合≥2、协同≥5、克制 `MIN_TAG`(默认8)。
- 所有推荐都**标注场次**（`games`），让用户知道可信度。

### 4.2 英雄总览
- 每英雄：`{name, wins, games, wr, wilson}`，按 wilson 降序。

### 4.3 单个符文胜率（最强）
- `WR(R|X) = 含R的对局中X的胜率`（出现即计入）。
- 分英雄 + 全局；按 wilson 排序；`MIN_GAME` 过滤。

### 4.4 最优符文组合
- **精确符文集合**（同一局带的一组符文）。**≥2个才算"组合"**（单个符文不算）。
- 最小样本≥2，按 wr 排序，取前20。
- 网站展示：每个符文名字+品质，附场次+胜率。

### 4.5 搭配增益（协同）
- 两两 pair：`wr(A&B)`，`lift = wr(A&B) − 该英雄整体wr`。
- 最小样本 ≥5；**按 wilson(WR(A&B)) 排序**（避免"小样本100%"顶到最前）。
- 网站展示：`A(品质) + B(品质)`、一起胜率（绿色）、`▲/▼ 增益%`（灰色，lift）。
- 小字说明：**"这两个符文一起带，胜率比该英雄平均▲高/▼低"**。

### 4.6 克制推荐（按敌方阵容）
- **逻辑**：对每个英雄，看其对局里**敌方阵容**出现的标签（召唤物/脆皮/坦克/刺客/治疗/远程/近战，来自 `champion_tags`）。对某敌方标签T、某符文R：`WR(R|X, 敌方含T)`。
- `lift = WR(R|X, T) − 该英雄整体wr`。
- **按符文去重**（一个符文一行，合并它能克制的多个敌方标签，如"刺客/坦克/近战"）；**只保留正增益**（比英雄平均高才有意义）。
- 网站展示：`[敌方类型] → 符文(品质) +X% (场次)`。
- 小字说明：**"敌方是这类阵容时，选这个符文克制"**。

### 4.7 核心出装
- 按英雄的 `items[:3]`（前3件核心）聚合；输出该英雄常见的核心三件套 + 胜率；按场次+胜率排序。
- 小字说明：**"该英雄这流派常见的核心三件套"**。

### 4.8 排除 A 类随机符文（重要）
- **A类**：`质变`（黄金阶/棱彩阶/混沌）和 `潘朵拉`——效果是"获得随机强化符文"，**结果随机、胜率虚高**（因为给的是棱彩）。
- 判定：`若名字含"质变"或"潘朵拉"则跳过`（`is_random_aug`）。
- **在所有推荐板块**（单个/组合/协同/克制/全局）都排除，避免误导。
- **但保留**：属性掉落器这类"几率触发效果"的符文（它们是确定性对位克制，不是纯随机事件）。

## 五、英雄标签 `champion_tags.json`（对位用）
- 来源：**DDragon 角色(role) + 攻击距离(attackRange) 自动推导**：
  - `attackRange≥400 → 远程`，否则 `近战`。
  - `Marksman/Mage/Assassin → 脆皮`；`Tank/Fighter → 坦克`；`Assassin → 刺客`。
- 人工补充：`召唤物`（马尔扎哈/大头/约里克/婕拉/伊莉丝/艾翁/安妮/阿兹尔）、`治疗`（索拉卡/娜美/琴女/露露/迦娜/塔里克/悠米/米利欧/幻翎/翠神）。
- 覆盖 **173 个英雄全部**（`build_tags_v2.py` 生成）。

> ⚠️ 标签是按"角色+攻击距离"自动推的，个别英雄可能不精准，可人工校正（用户可提供修正）。

## 六、输出 `processed\stats.json` 结构（供网站）
```
{
  "meta": {...},
  "champions": [ {id,name,wins,games,wr,wilson} ],        # 排行榜
  "champion_detail": {
      "<cid>": {
          "name", "overall":{wr,games,wins},
          "augments": [...],                 # 单个符文列表(已排A类,按wilson)
          "combos": [ {augments,wins,games,wr} ],   # ≥2术语组合
          "synergy": [ {a,b,wins,games,wr,lift,wilson} ],
          "builds": [ {items,item_names,wins,games,wr} ],
          "counters": [ {tag,augment,augment_name,wins,games,wr,lift} ]
      }
  },
  "augments_global": [ {id,name,wins,games,wr,wilson} ]   # 全局符文(已排A类)
}
```
（网站 `webapp.py` 在此基础上补 `name`/`quality`/`augment_meta`，并聚合成 `augments_by_quality`。）
