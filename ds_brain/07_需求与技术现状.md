# 需求与技术现状（ds_brain 07）

> 本文件整理**网站的功能需求、技术栈现状、技术债**，以及后续改进需求。供回顾/接手用。

---

## 一、项目概述
一个面向 LOL **「海克斯大乱斗」**（KIWI / `queue=2400`）的**英雄数据攻略站**：
- 主页：英雄胜率排行榜（按综合胜率/纯胜率/场次排序，可搜索、正倒序、分页），每行显示前3最优符文。
- 英雄详情页：整体胜率、最优单个符文（按品质分档）、最优符文组合、搭配增益、核心出装、克制推荐。
- 全部符文页、分类（6/多分类）页、个人中心、登录/注册、管理后台。

**核心判定标准 = 胜率**（真实对局数据驱动）。

---

## 二、已实现功能
- **数据管线**：WeGame 抓包探路 → curl_cffi 直连爬虫(BFS玩家图谱) → extract 清洗 → stats 统计(Wilson/收缩) → stats.json。
- **网站**：FastAPI 后端 + 单页前端(index.html)，HTTPS+域名上线 `https://haikelol.com`（Nginx 反代 + systemd）。
- **登录/认证**：注册(仅邮箱)/密码登录/邮箱验证码注册/忘记密码(163 SMTP 真发)/绑定手机号登录/**换绑邮箱**(向新邮箱发码验证)；角色体系(主管理员/管理员/普通用户)+管理后台；用户数据存 **SQLite**。
- **前端**：深/浅色主题、自定义背景(浅/深预设)、Q版桌宠(锁定)、密码框小眼睛、登录弹窗、个人中心。
- **装备推荐**：核心流派算法（玩家按顺序最早出的三件套成装；两件不同才算不同套；≥10场；收缩+Wilson下界）。
- **克制推荐**：按敌方阵容战斗属性标签（近战/远程/坦克/脆皮/刺客/治疗/召唤物），原始胜率算 lift。
- 页脚：ICP备案号、免责声明、Q版图出处(堆糖)、联系邮箱。

---

## 三、技术栈
- 后端：**Python + FastAPI**（单进程 uvicorn，`--workers 1`），SQLite 用户表，`.env` 配置 SMTP/备案号。
- 前端：**Vue 3 + Vite + SFC**（`havoc_guide/web/`，v1.1 起构建产物 `web/dist` 上线）。
- 数据：`processed/` 下 stats.json、champion_tags.json、completed_items.json、users.db 等；ddragon/communitydragon CDN 图标。
- 部署：阿里云 ECS(成都) + Ubuntu + systemd + Nginx + 免费SSL。
